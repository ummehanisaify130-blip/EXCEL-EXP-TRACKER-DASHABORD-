# 💰 Personal Expense Tracker - Excel Dashboard

### Project Overview
Built a complete expense tracker from raw `|` delimited text data (20 transactions, ₹3,902) in Excel.

### 🔧 What I Did
**1. Data Cleaning**
- Text to Columns (| delimiter)
- TRIM, DATEVALUE, Cleaned amounts

**2. Summary Sheet**
- SUMIF for category totals
- COUNTIF for frequency
- Percentage calculation

**3. Dashboard**
- Pie Chart: Expense Breakdown (Travel 47.41%)
- Bar Chart: Frequency of Expenses
- Dark theme professional design

### 📊 Key Insights
- Highest Spend: Travel ₹1,850 (47.41%)
- Most Frequent: Food & Travel (6x each)
- Average: ₹195.10 per transaction
